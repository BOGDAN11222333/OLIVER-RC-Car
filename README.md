# OLIVER RC CAR

## Project Description
ESP32-S3 based remote-controlled vehicle.

## Hardware
- ESP32-S3 Dev Module
- BTS7960 motor driver
- MG90S steering servo
- LED lighting
- Wi-Fi control
- BLE provisioning

## Software
- Arduino IDE
- ESP32 Arduino Core
- MIT App Inventor

## Development Status
Existing firmware architecture established.
Wi-Fi and BLE communication working.
Steering calibration implemented.

## Development Rules
- Preserve working communication protocols.
- Test each module independently.
- Record all hardware changes.
- Keep physically tested versions.
